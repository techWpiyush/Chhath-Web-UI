Create a polished, responsive festive landing page inspired by Chhath and Tihar, with a strong focus on UI/UX, animation, and visual storytelling.

Before coding:
- Inspect the existing project structure, framework, styling approach, and available assets. Work with the existing stack and conventions; don’t replace or restructure unrelated parts.
- Use the installed `ui-ux-pro-max` skill for the design system and interface decisions.
- Use the relevant GSAP skills: `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, and `gsap-performance`. If this project uses React, also use `gsap-react`.
- Check the skills’ `SKILL.md` guidance before implementing.

Creative direction:
- Tell a warm, meaningful story that connects the festivals through light, gratitude, devotion, family, and renewal.
- Let Chhath and Tihar each have their own distinct visual identity while making the page feel like one cohesive celebration.
- Use an elegant, contemporary visual style—not a generic festival template. Consider the glow of diyos, sunrise and water reflections, marigold colors, subtle patterns, and atmospheric gradients.
- Be respectful and culturally thoughtful. Don’t invent rituals or present uncertain details as fact. Use concise, accessible copy; keep existing project content where appropriate.

Page experience:
- Build a compelling opening hero with a clear headline, short supporting copy, and a meaningful primary action.
- Guide visitors through a story-led sequence of festival moments, traditions, or themes.
- Include a clear transition between Chhath and Tihar, and finish with a memorable closing section and call to action.
- Make the page work beautifully on mobile, tablet, and desktop, with readable typography, comfortable spacing, accessible contrast, and intuitive navigation.
- Use real project assets if available. If not, create the visual atmosphere with CSS and existing dependencies rather than adding arbitrary stock imagery or unnecessary packages.

Animation direction:
- Use GSAP to support the story, not distract from it: gentle hero reveals, layered movement, and carefully timed section transitions or scroll-triggered moments.
- Keep motion smooth and restrained; avoid excessive parallax, long delays, and animation that blocks interaction.
- Scope and clean up animations appropriately for the project framework. Avoid layout-thrashing properties where possible.
- Respect `prefers-reduced-motion`; provide a calm, usable experience when motion is reduced.
- Ensure animations don’t cause horizontal overflow, text clipping, or poor mobile performance.

Implementation:
- Implement the page in the project rather than returning only a mockup or plan.
- Reuse existing components and design conventions where practical, and keep the code maintainable.
- Verify the result with the project’s available checks. Fix issues caused by the implementation and report what changed and what you verified.
